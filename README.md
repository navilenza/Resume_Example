# GEI-CAR
Extrait de code fait dans le cadre du projet de fin d'étude en SIEC (Système Informatique Embarqué Critique)
 - Caractérisation de l'IMU avec Python
 - Ecriture du noeud pour l'ESP avec ROS2 (Publisher/Subscriber)
 - Developpement de la pipeline pour la detection de ligne avec Open CV (test sur un notebook jupyter et fichier python)
 - Documentation de developpement (Plan de developpement SDF et plan developpement orienté projet)

Repertoire complet:  https://github.com/pofpifpaf/geicar-kleya

# TIM_BLE

Composition du dossier:
- Image du design réalisé qui sert de références pour la personne développant l'interface mobile
- Extrait des drivers pour MCP2515 et drivers CAN
- Extrait de la logique de l'application
